# OpenIQ 2.3 — norming and psychometric validation protocol

This update adds a draft research-protocol section to the existing 60-item practice website.

## Included in the site
- A staged study plan: construct definition, cognitive interviews/usability, pilot analysis, norming and validation.
- A preregistration planning table for item functioning, reliability, validity, fairness, and representativeness.
- Data minimization and privacy planning.
- Release gates that keep IQ conversion disabled until evidence is independently reviewed.

## Important
This is a protocol scaffold, not a completed norming or validation study. It does not provide norms, psychometric results, or an IQ score. Do not collect participant data until the protocol, consent, privacy plan, recruitment materials, and any required ethics review are approved by qualified people. A qualified psychometrician should tailor the statistical methods and sample-size plan to the target population and intended score interpretation.
