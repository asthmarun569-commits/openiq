# OpenIQ — Recreated Recovery Build

This is a recreated, static-only OpenIQ practice assessment intended to restore a working website entry point safely.

## Deploy on GitHub Pages
1. Keep a backup of the current repository first.
2. Upload `index.html` to the **root** of the `main` branch.
3. In Settings → Pages, keep the existing source `Deploy from a branch`, branch `main`, folder `/(root)`.
4. Wait for the Pages deployment to finish, then open the repository's Pages URL.

## Scope and limits
- Standalone HTML; no build step or external dependency.
- Does not connect to Supabase or submit user data to a server.
- Exports a JSON result only when the user taps Download result JSON.
- Contains 12 demonstration questions and raw scoring only.
- Not a validated IQ test; do not interpret raw scores as IQ, percentile, or clinical information.
- This is a fresh recreation, **not an exact restoration** of the original v0.13.1 archive or deleted research assets.
