# OpenIQ 2.1 — expanded question bank

This package includes a 60-item practice bank: 15 items each in pattern reasoning, verbal reasoning, working memory, and quantitative reasoning.

The website reports raw scores only. The question bank is an educational prototype and is not a standardized or validated IQ instrument. It must not be used for diagnosis, hiring, or other high-stakes decisions.

Pilot CSV analysis is exploratory and runs in the browser. Community proposals are saved locally and must be exported to share; they do not automatically reach maintainers.

## Publish
Replace the repository's existing `index.html` with the included file and commit it to the branch used by GitHub Pages. This artifact has not been committed or deployed by this tool.
