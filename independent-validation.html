Independent validation against a reference assessment

This page guides a study comparing a frozen OpenIQ release with a suitable independently administered reference cognitive assessment. It is a protocol and readiness checklist—not evidence that validation has already occurred.

Current status: not validated

OpenIQ currently produces raw practice scores. Do not compare these raw percentages with reference IQ scores, call the output IQ, or enable public IQ conversion. A valid comparison requires compatible score interpretations and a prespecified, independently reviewed study.

Study stages

  1. Choose the reference assessment. Use an established instrument suitable for the intended adult population, language, and construct. Follow its manual, licensing conditions, and administrator qualification requirements. A casual online quiz is not a suitable reference.
  2. Obtain review and consent. Determine applicable ethics-review requirements before recruitment. Explain purpose, procedures, risks, privacy, data retention, and withdrawal rights. Use pseudonymous codes and never put participant-level records in a public repository.
  3. Freeze OpenIQ. Archive the exact release, item bank, scoring, timing, device/browser conditions, and analysis script. Record version and file hashes. Do not change the test after inspecting confirmatory outcomes.
  4. Pre-register the protocol. Define target population, sampling plan, sample-size justification, inclusion/exclusion rules, test order, time interval, missing-data handling, outcomes, subgroup analyses, and the agreement threshold before confirmatory recruitment.
  5. Separate development from validation. Any score mapping is fitted only on calibration participants. The final validation participants must not be used to tune items, select the mapping, or choose exclusions. Prefer a later independent sample for replication.
  6. Analyse agreement, not correlation alone. Report bias, MAE, RMSE, score-range error patterns, and the proportion within the prespecified tolerance with a 95% confidence interval. Have a qualified psychometrician/statistician review the analysis.

Proposed primary outcome

Only if both measures yield defensible, comparable IQ-point scores: proportion of eligible independent validation participants whose absolute score difference is no more than 5 points. A proposed stringent success rule is that the lower bound of a prespecified two-sided 95% confidence interval is at least 95%. This is a demanding target and needs a formal sample-size plan.

difference = OpenIQ score − reference score

Report mean signed error, mean absolute error, root mean squared error, confidence interval for within-5 agreement, and prespecified subgroup results. Correlation by itself does not show agreement.

Important limits

A strong result in one sample does not automatically establish representative norms, test–retest reliability, construct validity, fairness, or generalizability. Norms require a suitable sample from the population for which scores will be interpreted. Any test changes after validation require appropriate re-evaluation. Do not reproduce protected reference-test items or norm tables.
