OpenIQ assessment workspace

Practice assessment, item-bank management and a structured validation plan in one workspace. This is a correctable, editable prototype. You can revise questions, options, answer keys, domains and settings in the editor, then export your question bank for backup.

Research limitation: This practice assessment is not a validated IQ test. Its raw score is not an IQ score, diagnosis, percentile or measure of a person's worth. Items and scoring require independent psychometric review before research or high-stakes use.

Proposed 95% accuracy criterion

For a future validation study, define accuracy before data collection. One possible criterion is that at least 95% of participants' OpenIQ scores fall within ±5 points of a suitable, independently administered reference assessment, with a pre-specified confidence-interval rule. This is only an example: the reference instrument, score scale, population, uncertainty and ethical approvals must be justified by qualified researchers.

Stage 1 · Content review

Map each item to a defined construct; review ambiguity, answer keys, cultural and language fairness, accessibility and difficulty.

Gate: expert approval

Stage 2 · Technical QA

Test mobile layouts, timer behaviour, navigation, unanswered items, data exports, import validation, keyboard use and browser compatibility.

Gate: no critical defects

Stage 3 · Pilot study

Use an approved protocol and consent process. Analyse item difficulty, discrimination, missingness, completion time and subgroup concerns.

Gate: acceptable item performance

Stage 4 · Psychometric study

Evaluate reliability, convergent evidence, measurement error, fairness and any proposed norms on an appropriate sample with independent oversight.

Gate: independent review

Release checklist

Important distinction

OpenIQ currently calculates only correct answers and domain-level raw counts. Those results describe performance on this particular demo set; they cannot establish general intelligence or be converted into an IQ score without substantial independent evidence.

Question editor

Changes apply to this browser session. Export the question bank to keep a backup. You can add one question or generate batches without a fixed app-level question limit. Every question must have a prompt, a domain, four non-empty options and one valid answer key.

AI question generator

Generate original multiple-choice questions with answer keys and explanations. Generate 1–50 questions per batch and repeat as needed. Review every question before using it. This is not a validated IQ test.

Use only the publishable key from your Supabase project. Never enter a secret or service-role key.

Unlimited question-bank setup

Add questions one at a time or create a batch of blank questions. There is no fixed question-count limit in the app code; practical limits depend on your browser and device memory. Export backups regularly.

Import and export

Use these tools to back up or move your question bank. Import replaces the current bank only after the JSON passes validation. Exported result files may contain answers; store them privately.

Data and privacy

  • This file runs locally in your browser; it has no server connection or Supabase integration.
  • Answers are held in page memory during the session. They are not silently uploaded.
  • Exported JSON and CSV files are downloaded to your device when you request them.
  • Never place secret keys in this HTML file. A production database requires a secure backend and access-policy testing.
