Proposed 95% accuracy criterion

For a future validation study, define accuracy before data collection. One possible criterion is that at least 95% of participants' OpenIQ scores fall within ±5 points of a suitable, independently administered reference assessment, with a pre-specified confidence-interval rule. This is only an example: the reference instrument, score scale, population, uncertainty and ethical approvals must be justified by qualified researchers.

Stage 1 · Content review

Map each item to a defined construct; review ambiguity, answer keys, cultural and language fairness, accessibility and difficulty.

Gate: expert approval

Stage 2 · Technical QA

Test mobile layouts, timer behaviour, navigation, unanswered items, data exports, import validation, keyboard use and browser compatibility.

Gate: no critical defects

Stage 3 · Pilot study

Use an approved protocol and consent process. Analyse item difficulty, discrimination, missingness, completion time and subgroup concerns.

Gate: acceptable item performance

Stage 4 · Psychometric study

Evaluate reliability, convergent evidence, measurement error, fairness and any proposed norms on an appropriate sample with independent oversight.

Gate: independent review

Release checklist

Research data collection readiness

Participant collection is not enabled in this static build. Phase 2 connects authenticated researcher workflows to the owner-controlled study and immutable version tables. Participant response collection remains disabled until a dedicated server-side submission endpoint, approved protocol, final consent language, retention/deletion workflow, and access-control testing are completed.

Each completed browser attempt now captures a frozen copy of the items, keys, order, timing, scoring rule and version label in the exported result JSON. This improves traceability but is not a cryptographically signed or server-verified record.

Important distinction

OpenIQ currently calculates only correct answers and domain-level raw counts. Those results describe performance on this particular demo set; they cannot establish general intelligence or be converted into an IQ score without substantial independent evidence.

Question editor

Sign in to save the question bank to Supabase. Export a JSON backup regularly. You can add one question or generate batches without a fixed app-level question limit. Every question must have a prompt, a domain, four non-empty options and one valid answer key.

Assessment version snapshots

Freeze a specific form for traceable pilot work. Snapshots are saved in this browser and can be exported; they are not a secure server-side archive until the database migration is installed and connected.

A snapshot can be created only when every item is marked Approved for pilot and has a reviewer, review date, and review notes. This is an editorial gate, not evidence that the test is psychometrically validated. The current practice Start button still runs the active question bank; selecting and administering a saved snapshot is a later integration step, so do not use this build to collect pilot data.

Import and export

Use these tools to back up or move your question bank. Import replaces the current bank only after the JSON passes validation. Exported result files may contain answers; store them privately.

Data and privacy

  • Question-bank cloud storage is available only after signing in; the signed-in account can access its own bank under Row Level Security.
  • Assessment responses remain in browser memory unless you explicitly export them.
  • Exported JSON and CSV files are downloaded to your device when you request them.
  • Never place secret keys in this HTML file. A production database requires a secure backend and access-policy testing.
  • Research participant response collection is intentionally not enabled in this static page. Do not collect live study responses until the research schema is installed, consent/protocol details are approved, and a server-side submission endpoint with rate limiting and access controls is deployed.
