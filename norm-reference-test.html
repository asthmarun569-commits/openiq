Norm-reference conversion test

This tool tests whether a mapping from OpenIQ raw scores to an independently obtained reference IQ score generalizes to held-out participants. It does not enable IQ reporting on the public test.

Critical requirements

Use only consented adult participant records from an appropriate, well-documented study. The reference assessment must be suitable and administered/scored independently by qualified personnel. Never upload names, email addresses, or other direct identifiers. Do not use simulated records as evidence.

1. Upload paired study data

CSV must include these columns: participant_code,openiq_raw_score,reference_iq,age_band,split. The split value must be calibration or validation. Fit the linear mapping on calibration rows only; assess it only on held-out validation rows. Use a prespecified split, not one selected after seeing results.
